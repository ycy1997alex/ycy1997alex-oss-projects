# 登陸艇下降段：光學掃描 → ICP/NDT 地形相對導航 → 最佳降落點選擇

模擬登陸艇在降落固體行星表面之前，以光學感測掃描地表，用 **ICP** 與 **NDT** 兩種點雲配準演算法修正導航誤差，融合出高解析地形，再逐格做危害分析並選出最佳降落點。

純 Python 實作，只依賴 `numpy` / `scipy` / `matplotlib`，不需要 PCL、Open3D 或任何點雲函式庫。

## 演算法管線

```
[0] 合成行星表面真值地形
      碎形基底(1/f^β 濾波白噪聲) + 撞擊坑(碗狀凹陷+隆起坑緣) + 岩塊 + 區域傾斜
                    │
      ┌─────────────┴─────────────┐
[1a] 軌道器先驗地圖             [1b] 下降段光學掃描
     格距 0.5 m、σz 0.10 m           6 幀，高度 900 → 250 m
     大範圍、低雜訊                   足跡半徑 47 → 13 m
     ＝配準的 target                  導航位姿含漂移誤差
      └─────────────┬─────────────┘
                    ▼
[2] 點雲配準（ICP / NDT / Hybrid）→ 修正每一幀的位姿
                    ▼
[3] 多幀融合 → 0.5 m 解析度 DEM
                    ▼
[4] 危害分析：以 2.5 m 著陸足跡半徑逐格做加權最小平方平面擬合
      坡度 · 粗糙度 · 最大凸起 · 資料覆蓋率
                    ▼
[5] 硬性約束篩選 → 加權評分 → 非極大值抑制 → Top-5 候選點
```

### 為什麼需要配準

登陸艇的慣性導航會隨時間漂移，掃描時「以為自己在哪裡」與「實際在哪裡」有數公尺的落差。若直接用導航位姿把六幀點雲疊起來，地形會被塗糊到完全無法做危害判定（本模擬中未配準的地圖 RMSE 為 **7.5 m**）。配準的作用就是把每一幀對齊到軌道器先驗地圖，把這個誤差壓到公分級。

## 兩種配準演算法

### ICP（Iterative Closest Point，point-to-plane）

殘差定義為對應點沿目標法線方向的距離：

```
r_i = (R·p_i + t − q_i) · n_i
```

以繞地面質心的小量 `δ = [δω, δt]` 線性化，解 Gauss-Newton 正規方程 `(AᵀWA)δ = −AᵀWr`。

實作要點：

- **point-to-plane 而非 point-to-point**。行星表面近似平面，point-to-plane 只懲罰法線方向的偏差、允許點沿切平面滑動，收斂速度快一個數量級。
- **Huber 強健權重**（以 MAD 估計尺度）壓制岩塊、離群點與掃描邊緣。
- **對應距離退火**：搜尋半徑從 8 m 以 0.88 的比例逐步收斂到 0.8 m，等效於多解析度策略——初期容忍大位移以擴大收斂盆地，後期收緊以逼出次公尺精度。

### NDT（Normal Distributions Transform）

把 target 點雲體素化，每個體素以一個 3D 高斯 `N(μ, Σ)` 描述局部表面分佈，最大化：

```
score(θ) = Σᵢ Σⱼ exp(−½ dᵀ Σ⁻¹ d),   d = x'ᵢ − μⱼ
```

實作要點：

- 解析梯度 `g = Σ e·(Σ⁻¹d)ᵀJ`，近似 Hessian `H ≈ Σ e·JᵀΣ⁻¹J`（丟棄負定項以保證正定），配 backtracking line search 加步長擴張。
- 與 ICP 共用同一組局部參數化與 Jacobian `J = [−[x−c]×, I]`，兩者才能公平比較。
- **共變異數膨脹退火** `Σ_eff = Σ + σ₀²I`，金字塔為 (6 m, 0.80 m) → (3 m, 0.30 m) → (1.5 m, 0.08 m)。

> **關於膨脹退火**：這是讓 NDT 在近平面地形上真正可用的關鍵。體素高斯在法線方向極薄（`Σ_zz ~ 0.01 m²`），數公尺初始誤差下指數項會直接下溢為零、梯度消失。膨脹等同對目標機率場做高斯平滑，由粗到細逐級縮小 `σ₀`，概念上與 CPD / GMMReg 的 annealing 一致。沒有這一步，NDT 在本場景會直接發散。

### Hybrid

先跑 NDT 金字塔取得粗對位，再以較緊的對應距離（4.0 → 0.5 m）跑 ICP 精修。

### 實測比較（seed 7）

| 方法 | 地圖 RMSE | 位姿誤差 @ 感測器 | 平均迭代 | 耗時 / 幀 |
|---|---|---|---|---|
| 未配準（純導航） | 7.536 m | — | — | — |
| ICP | **0.022 m** | 0.106 m / 0.05° | 49 | 178 ms |
| NDT | 1.369 m | 1.427 m / 0.52° | 43 | 1594 ms |
| Hybrid | **0.022 m** | 0.109 m / 0.05° | 47 | 167 ms |

收斂盆地（成功判定：地圖 RMSE < 0.3 m，每級 8 次試驗）：

| 初始水平誤差 | 2 m | 5 m | 10 m | 20 m | 35 m |
|---|---|---|---|---|---|
| ICP | 100% | 100% | 100% | 62% | 0% |
| NDT | 100% | 100% | 75% | 0% | 0% |

**NDT 在本場景並未展現教科書宣稱的「收斂盆地更寬」的優勢。** 原因有二：退火式 ICP 已經涵蓋了同樣的功能；而地形近似平面使 NDT 的體素高斯無法提供有效的水平約束。這個結論限於此類低起伏地形，不宜外推到城市或室內點雲。

NDT 慢約一個數量級，是因為使用近似 Hessian 且在線搜尋中重複評估分數。正式飛控實作應改用完整解析 Hessian 與快取查表。

## 危害分析與評分

對每一格，取半徑 2.5 m（著陸足跡）的圓形視窗，做加權最小平方平面擬合 `z ≈ a·dx + b·dy + c`：

| 指標 | 定義 | 為何重要 | 預設門檻 |
|---|---|---|---|
| 坡度 | `atan(√(a²+b²))` | 翻覆風險、推力向量餘裕 | ≤ 10° |
| 粗糙度 | 殘差 RMS | 著陸腳架接觸品質 | ≤ 0.14 m |
| 最大凸起 | 視窗內去趨勢後的最大值 | 岩塊會頂穿或架空登陸艇 | ≤ 0.30 m |
| 覆蓋率 | 有效格點比例 | 感測資料是否足夠可信 | ≥ 75% |
| 轉向距離 | 到標稱目標的水平距離 | 燃料代價 | ≤ 30 m |

九個統計量以 `scipy.ndimage.correlate` 一次算完（`O(N × kernel)`），不需要逐點做 KD-tree 半徑查詢。

**最大凸起的基準是該格「自身的局部擬合平面」，不是視窗均值。** 若用視窗均值當基準，斜坡本身就會被誤判成 0.5 m 級的凸起，導致全域無解——這是實作時踩過的坑。

綜合分數（權重預設 34 / 26 / 24 / 6 / 10，自動正規化）：

```
score = Σ wₖ · fₖ,   fₖ = clip(1 − 指標 / 門檻, 0, 1)
```

任一硬性約束違反則分數歸零。最後以非極大值抑制（最小間隔 5 m）取前 5 名，避免候選點全部擠在同一塊平地上。

## 互動式圖版

`landing_site_plate.html` 是單一檔案、離線可開，雙擊即可。

**運作方式**：重的計算（配準、融合、平面擬合）已經固化成資料，危害圖以 uint8 量化後 base64 內嵌；門檻重算、評分、非極大值抑制全部跑在瀏覽器端。所以拉滑桿是即時的，不需要重跑模擬。

**可操作**

- 五個硬性門檻滑桿：坡度 / 粗糙度 / 凸起 / 覆蓋率 / 轉向距離
- 五個評分權重滑桿（自動正規化為總和 1）
- 五種檢視模式：安全分數 / 限制因子 / 坡度 / 粗糙度 / 最大凸起
- **點圖版任一處可改設標稱目標點**，轉向距離與虛線圓會跟著重算
- 游標移到圖版上可讀取單點數值

**「限制因子」的讀法**

不可著陸區以對角影線標示，線色即對應**最嚴重的超標項目**：紅＝坡度、紫＝粗糙度、銅＝凸起、灰＝覆蓋率。這樣一眼就看得出放寬哪個門檻才換得到面積。轉向超標不畫影線，因為虛線圓已經說明同一件事。

**量化誤差**：坡度分級 0.1°、粗糙度 2 mm、凸起 4 mm。對候選點排序無影響，分數差約 0.005，可著陸面積差約 3%。

## 輸出如何解讀

### 文字報告

`[2]` 逐幀表格用的是**地圖空間 RMSE**（配準後地面點相對真值的 RMS 位移），不是位姿誤差。

> 這個選擇很重要。位姿誤差在感測器原點量測，會被力臂效應嚴重放大——640 m 高度下 0.05° 的偏航誤差就換算成數十公尺的「位姿誤差」，但地面點其實只偏了幾公分。**直接決定融合 DEM 品質的是地圖空間 RMSE**，位姿誤差只列在摘要供參考。

`[5]` 候選點表格最後會用真值地形驗證第一名，可以看出估測值與真值的差距。seed 7 的結果是估測 1.83° / 0.054 m、真值 1.70° / 0.049 m。

## 已知限制

程式開頭有完整聲明，摘要如下：

1. **光學感測被抽象化為「已還原的 3D 點雲」**。未模擬影像形成、立體匹配失敗、低太陽角下的長陰影與飽和、行星塵埃反光等真實光學退化。

2. **軌道器先驗地圖由同一份真值地形取樣而來**，只含隨機雜訊、無系統性地圖偏差。真實 TRN 的先驗地圖本身即有數公尺級的絕對定位誤差，配準精度會被該誤差限制住。這是本模擬能達到公分級精度的主要原因。

3. **水平位置的可觀測性完全來自地形起伏**。若降落區極度平坦（如平滑月海），ICP 與 NDT 的水平方向皆會退化為病態問題，需改用影像特徵匹配或都卜勒/慣性輔助。

4. **未納入任務層級的約束**：下降段的即時性（每幀運算需在 GNC 週期內完成）、燃料最佳化的軌跡重規劃、光照 / 通訊 / 科學價值等選點準則。

5. **圖版顯示的坡度與粗糙度是估測值，不是真值**。誤差來自感測雜訊與 0.5 m 柵格化，量級約 0.1° / 5 mm。若把坡度門檻壓到 2° 以下，就進入誤差主導的區間，此時判定已不可靠。

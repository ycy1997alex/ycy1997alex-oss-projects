# UI 設計稿

圖形介面開工前畫的三個方向，以及被選上的那一張的原始檔。

## 三張稿

| 檔案 | 方向 | 結果 |
|---|---|---|
| `main-1x.png` | 白底、Bootstrap litera 色票、三段式版面 | **採用** |
| `console-dark-1x.png` | 深色終端機，左側固定側欄，每行掛毫秒時間戳 | 未採用 |
| `card-grouped-1x.png` | 米白底、圓角卡片、陰影、暖色系 | 未採用 |

`@1x` 的意思是一倍像素密度，檔名裡保留成 `-1x`。

選 Main 的理由不是它最好看，是 ttk 做得出來。CardGrouped 的圓角、陰影與卡片間距在 tkinter 裡沒有對應物，照著做只會做出一個處處差一點的東西；ConsoleDark 做得出來但會很痛，左邊那條固定側欄要用 `Panedwindow` 或一堆 grid 權重去撐，視窗一縮小就互相擠。

ConsoleDark 沒有浪費：它那組深色色票整組搬進程式當暗色主題，每行掛時間戳的做法也用在 notify 的 callback 上。

## `main-html/`

被選上那張的原始檔，是設計工具匯出的獨立頁面。**它是尺寸表，不是半成品**：顏色、字級、間距、圓角、陰影的精確值寫在行內 `style="…"` 與 `<helmet><style>` 裡，實作要用自己的元件重現這些數值，不是把它整段搬過去。

要看的話得起一個 HTTP server（`python -m http.server`）再開 `Main.dc.html`，有些瀏覽器會擋掉 `file://` 底下的腳本。細節見 `main-html/README.md`。

另外兩張沒有對應的原始檔，PNG 就是它們僅存的記錄。

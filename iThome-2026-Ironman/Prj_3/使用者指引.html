Mi Band 6 BLE Explorer

看看小米手環 6 在沒有配對的情況下，願意告訴電腦哪些事情
版本 v1　·　本指引對應 2026 年 8 月 31 日的版本　·　適用 Windows 10／11

這是什麼

這是一支只會看、不會動手的小工具。它用電腦的藍牙去問手環：你身上有哪些資料？ 哪些願意給我看？然後把問到的東西整理成人看得懂的字，顯示在畫面上。

它不會改動手環上的任何東西。不會寫入資料、不會改設定、不會刪除紀錄、不會更新韌體， 也不會嘗試「破解」需要密碼的部分。全程只有「讀」這一個動作。 所以放心按，按錯了頂多是看到一行錯誤訊息。

開始之前要準備的

  • 一台有藍牙的 Windows 電腦，藍牙是開著的。
  • 小米手環 6，戴在手上（放在桌上通常訊號會弱很多，而且螢幕暗掉之後它會變得比較安靜）。
  • 手環放在電腦旁邊，距離一公尺以內最穩。
  • 手機上的 Zepp Life 要先關掉。手環同一時間只肯讓一台裝置連線，手機沒放手，電腦就連不上。

要用的檔案只有一個：MiBand6BleExplorer.exe。不需要安裝，放哪裡都可以，雙擊就會打開。

快速開始

最常做的一件事是「看看手環現在的狀況」。從打開到看到結果，五步：

  1. 雙擊 MiBand6BleExplorer.exe 第一次打開比較慢，大約要等七秒視窗才會出現，之後大概四到五秒。中間沒有反應是正常的，不要連按好幾下。
  2. 按左下角綠色的 Scan 電腦開始找附近的藍牙裝置，預設找八秒。這段時間所有按鈕會變灰、游標變成等待的圈圈，那表示它正在忙。
  3. 在清單裡點一下手環那一列 名字通常是 Mi Smart Band 6，而且這一列的字會比較粗——粗體就是程式在說「這一個看起來是小米或華米的裝置」。
    找不到？先看下面〈常見問題與疑難排解〉裡「掃描找不到手環」那一條，多半是把秒數調大就好。
  4. 按 Connect 連線大約要十秒。成功之後左下角的字會變成綠色的 Connected，右邊那一排按鈕跟著亮起來。
  5. 按 Summary 這是最省事的一顆：它一次把七項基本資料讀回來——手環型號、序號、硬體與韌體版本、電量、電池細節、手環目前的時間， 直接用中文列在上方的紀錄區。
用完之後按 Disconnect 再關視窗最乾淨。忘了按也沒關係，直接關視窗， 程式會自己把連線收掉再結束——只是關閉的動作會多花一兩秒。

畫面導覽

整個程式只有一個視窗，由上到下分成三塊：上面是紀錄區（所有結果都印在這裡）， 中間是紀錄的存檔工具，下面是操作區。

區塊它在做什麼
1　紀錄區 所有結果都印在這裡，由上而下累積。有兩個分頁：
Communication Log：一般的訊息與讀到的資料。
GATT Structure：手環身上所有「資料格子」的完整清單，排成一棵可以收合的樹（實際有八十幾個項目）。 按過 Enumerate GATT 之後才會有內容。
2　Log Actions 把紀錄存成文字檔的地方，還有右邊的 Dark 開關可以切成深色畫面。細節看〈存下來的紀錄檔〉。
3　Device Connection 找裝置、選裝置、連線。Timeout 是「要找幾秒」， Named devices only 打開時只列出有名字的裝置（關掉會冒出一大堆沒有名字的，通常沒用）。
4　Explorer Actions 連線成功之後才會亮起來的五顆功能鍵，加上左下角的連線狀態與右下角目前選中的裝置。

四顆功能鍵各做什麼

按鈕做什麼大概要等多久
Enumerate GATT 把手環身上所有資料格子列成一棵樹，放到第二個分頁。這一步只是「看目錄」，不會真的去讀內容一兩秒
Read All 把每一個標示為「可讀」的格子都讀一次。會有一部分被手環拒絕，那是正常的十幾秒
Summary 最常用的一顆。只讀七項基本資料，直接用中文列出來兩三秒
Start Notify 換一種方式：不去問手環，而是坐著等它主動送東西過來。按下去之後字會變成 Stop Notify， 想停就再按一次要開多久由你決定

上面那個 Read UUID 欄位是給知道自己要什麼的人用的：填一組四位數的代號（例如 2a28） 按 Read，就只讀那一格。不知道要填什麼的話，用 Summary 就好。

看懂畫面上的東西

顏色代表什麼

藍色 — 程式在報告進度 綠色 — 成功讀到，而且看得懂 黃色 — 提醒，不是錯誤 紅色 — 這一項失敗了 紫色 — 這一行是某個資料格的名稱 灰色 — 原始資料或補充說明

Summary 的七項

項目怎麼看
裝置名稱手環自己報的名字，例如 Mi Smart Band 6
序號手環的出廠序號。這是識別資訊，要把畫面或紀錄檔給別人看之前，記得先遮掉
硬體版本出廠就固定的，不會變
韌體版本手環軟體的版本，更新韌體之後才會變
電池電量百分比，跟手環螢幕上看到的是同一個數字
電池詳情電量、是不是正在充電、兩個時間戳，還有上一次充飽時的電量。 其中兩個時間戳的確切意義沒有官方文件可查，程式只照原樣列出來，不保證解讀正確
手環時間手環自己的時鐘。這一項最值得看一眼：如果它跟你的手錶對得上， 表示從找裝置、連線、讀取到翻譯這一整條路都沒有出錯
第八行永遠是黃色的那句「即時步數：禁止直接讀取，請用 Start Notify」。 這不是失敗——手環就是不讓人主動去問步數，但它自己會一直送過來。想看步數請看下面。

裝置清單裡的 RSSI

訊號強度，單位是 dBm，永遠是負數，越接近零表示訊號越強。 手環戴在手上、放在電腦旁邊時大約落在 −50 上下；掉到 −80 以下大概就連不太起來了。 清單本來就是照訊號由強到弱排的，所以你的手環通常在很前面。

「讀取被拒」是正常的

按 Read All 之後，會看到最後有一段紅字列出幾個被拒絕的項目，訊息通常長得像 Read Not Permitted。這不是程式壞掉，是手環刻意鎖住的欄位—— 那些資料要先跟手環完成一次配對驗證才拿得到，而這支工具刻意不做那件事。

另外還有一種情況：讀是讀到了，但內容是空的（零個位元組）。那也是手環的選擇，不是讀取失敗。

看不懂的那一串十六進位

每讀到一格資料，程式會先原封不動印出它的原始內容，長得像 4d 69 20 53 6d 61 72 74  |Mi Smart|：左邊是原始數值，右邊直槓中間是「如果當成文字看會是什麼」。

如果程式看得懂這一格，下一行會多一句綠色、以 => 開頭的翻譯。 沒有那一行，就表示程式不確定這串數字是什麼意思，所以只把原樣留給你—— 這是刻意的，寧可不翻譯，也不猜一個看起來很像真的的答案給你。

Start Notify 會看到什麼

按下去之後，程式會把手環上所有「願意主動送東西」的格子全部訂閱起來，畫面上會告訴你訂閱了幾個。 接著就是等。實測下來，沒有配對驗證的情況下真的會講話的通常只有一個：即時步數。

  • 每一筆會帶一個帶毫秒的時間戳，方便對照當下發生了什麼。
  • 戴著手環走個幾十步，大約一秒左右就會推一筆過來，可以看到步數往上跳。
  • 坐著不動的話可能好幾分鐘都沒有動靜，那不是壞掉。
  • 看夠了按 Stop Notify；直接按 Disconnect 也會一併收掉。

GATT Structure 分頁

按過 Enumerate GATT 之後，第二個分頁會出現一棵樹： 最外層是「服務」（一組相關資料的集合），點開是「特徵」（一個個具體的資料格）， 再點開是「描述元」（那一格的附註）。每一列右邊會標出它的完整代號、能做哪些事（read／notify …）。

實測一支手環大約有八十幾個項目，一頁放不下是正常的。 這裡是拿來「看看手環身上到底有些什麼」的地圖，不看也不影響前面任何一個功能。

存下來的紀錄檔

畫面上的內容不會自動保存，關掉視窗就沒了。要留下來有兩種方式：

按鈕做什麼什麼時候用
Save Printed Log 把現在畫面上已經有的內容一次存成一個文字檔 事情做完了，想留個紀錄
Start to Save Log 從按下去的那一刻起，之後每一行都邊出現邊寫進檔案，每行前面加上時間 要開著 Start Notify 等很久的時候。中途當掉也不會白等
Finish to Save Log 結束上面那種即時紀錄，把檔案收好 錄完了。忘記按也沒關係，關視窗時程式會自己收尾
Clear Log Window 清空畫面上的紀錄。只清畫面，已經存成檔案的不受影響 畫面太亂，想重新開始看
Path to Save 換一個資料夾放這些檔案 想存到別的地方時

檔案存在哪、叫什麼

預設放在你的「文件」資料夾底下一個叫 MiBand6_Explorer_Log 的資料夾裡， 再依日期分成子資料夾。目前的路徑一直顯示在 Path to Save 右邊那一欄，看一眼就知道。

檔名長這樣：

MiBand6_Log-Printed_20260830-142544.txt

  • Printed＝一次存下來的；Interval＝邊跑邊寫的。
  • 後面兩組數字是日期與時間（20260830 就是 2026 年 8 月 30 日）。

都是純文字檔，用記事本或任何文字編輯器打開就好，內容跟畫面上看到的一樣，只是沒有顏色。

分享之前先看一眼。紀錄檔裡會包含手環的序號與藍牙位址，那些屬於裝置的識別資訊。 要貼到網路上或傳給別人之前，把它們遮掉。要注意同一組位址可能以另一種寫法在檔案裡出現不只一次， 所以最好整份搜尋過一遍，而不是只改開頭那幾行。

使用建議與限制

用起來比較順的做法

  • 先按 Summary，再考慮其他的。七項基本資料就足以回答大部分問題，而且最快。
  • 一次只按一顆。程式忙的時候按鈕會全部變灰，等它們亮回來再按下一顆。硬按沒有用，畫面會告訴你上一個還在跑。
  • 手環戴在手上。螢幕暗掉之後手環會變安靜，訊號也弱，放桌上不好找。抬個手把螢幕點亮再掃描，成功率高很多。
  • 掃不到就把秒數調大。八秒是預設值，二十秒常常就找到了。這件事有運氣成分，同樣的設定跑兩次結果可能不一樣。
  • 要等很久就先開即時存檔。尤其是 Start Notify。

它做不到的事

限制說明
拿不到心率、睡眠、詳細運動紀錄 這些欄位手環要求先完成配對驗證，而這支工具刻意不做那一步。這是設計上的選擇，不是故障
不能修改手環不能改設定、不能對時、不能刪資料、不能更新韌體。它只會看
一次只能一台裝置連手環手機的 Zepp Life 開著就連不上，反過來也一樣：這裡連著的時候，手機會連不上
斷線發生在讀取途中會洗版如果讀到一半手環走遠了，剩下的項目會一個一個失敗、每個印一行紅字。 重新連線再來一次就好
看得懂的欄位有限看不懂的一律只顯示原始數值，不亂猜
只在 Windows 上用過Windows 10 與 11 都可以
視窗不能縮太小低於一定寬度版面會擠在一起，建議維持打開時的大小
看到的數字只代表當下那一次。訊號強度、掃描要幾秒、兩分鐘內收到幾筆步數， 這些每次跑都可能不一樣。它們是觀察紀錄，不是規格。

常見問題與疑難排解

雙擊之後好像沒反應
先等一下——第一次打開要把內容解開，大約七秒視窗才會出現，之後每次也要四到五秒。 這段時間畫面上完全沒有提示是正常的。不要連按好幾下，那樣會同時開好幾個。 等超過三十秒還是沒有視窗，才需要換個資料夾（例如桌面）再試一次。
掃描找不到手環
照這個順序試：
  1. 抬手把手環螢幕點亮，馬上按 Scan。手環在螢幕暗著的時候會變得比較安靜，比較難被找到。
  2. 把 Timeout 從 8 調到 20，再掃一次。
  3. 把手環拿到電腦旁邊，一公尺以內。
  4. 確認電腦的藍牙是開著的（Windows 設定裡看得到）。
這件事本來就有運氣成分，同樣的設定連掃兩次，一次找得到一次找不到，是常見的。
連線失敗，畫面出現一行紅字
最常見的原因只有一個：手機上的 Zepp Life 還連著手環。手環同一時間只肯讓一台裝置連線。 把手機的藍牙關掉，或把 Zepp Life 完全結束掉，再按一次 Connect。 程式在失敗訊息底下也會直接提醒這一點。

排除之後還是連不上的話，重新掃描一次拿到新的結果再連——舊的掃描結果放太久會失效。
連上了，過一下子自己斷掉
通常是走太遠或手環電量低。畫面會自動變回未連線的樣子，按鈕也會收起來，重新 Connect 即可。 如果是斷在 Read All 跑到一半，會看到一連串紅字，那是後面每一項都失敗了，直接重來就好。
按鈕全都是灰的，按不下去
兩種可能：
  • 正在忙。游標會變成等待的圈圈，等它跑完就會恢復。掃描八秒、連線十秒、Read All 十幾秒都算正常。
  • 還沒連線。右邊那五顆要連線成功才會亮。左下角顯示綠色的 Connected 才算連上。
另外 Connect 要先在清單裡點一列才會亮。
Read All 之後出現好幾行紅色的「讀取被拒」
正常。那些是手環刻意鎖住、需要先完成配對驗證才拿得到的欄位，而這支工具刻意不做那件事。 被拒的項目會集中列在最後，附上手環給的原因。真正讀到的資料在上面。
開了 Start Notify，等半天什麼都沒有
先確認畫面上有一行說訂閱成功了幾個。有的話就是手環暫時沒有東西要說。 戴著手環走個幾十步，即時步數大約一秒一筆就會開始進來。 沒有配對驗證的情況下，真的會主動送東西過來的通常只有這一項，其他訂閱了也是安靜的。
畫面看久了眼睛痛
右下角有一個 Dark 開關，切過去整個介面連同紀錄區都會變成深色。 隨時可以切回來，不影響任何正在進行的事情。
找不到剛剛存的檔案
看 Path to Save 右邊那一欄顯示的資料夾，檔案就在那底下、依日期分的子資料夾裡。 預設是「文件」資料夾裡的 MiBand6_Explorer_Log。 存檔成功時畫面上也會印一行綠色訊息，寫著完整位置。
關視窗的時候卡了一下
正常。關閉之前程式會先把連線好好斷開、把紀錄檔收好，最多等五秒。 等它自己關掉就好，不需要去工作管理員強制結束。
用這支工具會不會把手環弄壞
不會。它全程只有「讀」這一個動作：不寫入、不改設定、不刪資料、不更新韌體， 也不會嘗試繞過手環的驗證。手環上的資料與設定不會有任何改變。

## Overview

This is a public **collection repo** for small projects and demos I've put together and want to share. It's a grab bag: some pieces were built together with Claude / Codex, others I wrote entirely on my own. Tech stack, language, and maturity are not expected to be consistent across entries. The whole repo is licensed under the [MIT License](LICENSE), unless a subproject's own folder states a different license — in that case, the subproject's statement takes precedence.

This is not a single product, so there is no overall architecture or unified build process — each subproject is an independent unit with its own documentation, dependencies, and run instructions. This file is only an **entry point and index**.

## Directory structure

```
ycy1997alex-oss-projects/
├── README.md              This repo's index, Traditional Chinese
├── README.en.md           English version, cross-linked with README.md
├── LICENSE                MIT License

    └── README.md
```

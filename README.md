繁體中文 | [English](README.en.md)

## Overview

這是一個公開分享用的**集錦 repo**，收錄我陸續做出來的小型專案與 demo。內容是大雜燴：有和 Claude / Codex 一起合作完成的作品，也有我自己獨立完成的作品，技術或語言成熟度都不強求一致。整個 repo 採 [MIT License](LICENSE)，除非某個子專案資料夾裡另外標明不同授權，否則一律以本檔案為準。

這裡不是單一產品，沒有整體架構或統一的建置流程。每個子專案都是獨立單元，各自有自己的說明文件、依賴與執行方式。本檔案的角色只是**入口與索引**。

## Directory structure

```
ycy1997alex-oss-projects/
├── README.md              本檔案（繁體中文）
├── README.en.md           英文版，兩者互相連結切換
├── LICENSE                MIT License
└── <project-name>/        子專案，各自附一份 README.md 說明用途與執行方式
    └── README.md
```
